Colors

Scales, semantic roles and the contrast every pair passes.

Code uses roles, never raw values: bg-primary, text-muted-foreground, border-border. Each role has a value for light and dark mode, built from the scales below.

Scales

The brand scale grows from one color, oklch(0.49 0.13 256). The grays are cool.
