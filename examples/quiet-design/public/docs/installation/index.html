Installation

Add the system to an app, import its fonts and check the result.

The system works in any React app on Tailwind CSS v4: Next.js, Vite, React Router or Astro.

Add it to your app

Run this in the app's folder. It installs the theme, every component, DESIGN.md and the guardrails, points AGENTS.md and CLAUDE.md at the rules, and registers the MCP server for coding agents.

npx auto-design add {origin}/r/ --components all

To add only some components, list them: --components button,card,dialog.

Import the fonts

Once, in the root layout. The fonts are open source and install from npm with the system.

import "@fontsource-variable/geist";
import "@fontsource-variable/geist-mono";

Check your work

The check reads the guardrails and fails on anything off the system: raw colors, palette classes, sizes and spacing outside the scales.

npx auto-design check

See Guardrails for every rule.

With the shadcn CLI

The system is also a shadcn registry. Install the base first, then components one at a time.

npx shadcn@latest add {origin}/r/base.json
npx shadcn@latest add {origin}/r/button.json
