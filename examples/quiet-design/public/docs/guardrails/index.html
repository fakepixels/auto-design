Guardrails

What the check enforces, and how to make an exception.

The theme is locked: Tailwind's default palette, sizes, radii and shadows are removed, so off-system classes don't exist. The check catches the rest, in code and CSS, and fails the build.

npx auto-design check            # lint the project against these rules
npx auto-design check --json     # machine-readable, for agents
Rule Severity What it enforces
no-raw-color error Colors come from semantic roles, never hex, rgb, hsl or oklch literals.
no-palette-color error Tailwind palette colors (bg-blue-500, text-white) do not exist in this system.
no-arbitrary-value error No arbitrary values for color, type, spacing, radius, shadow or motion (p-[13px], text-[#333]).
type-scale error Text sizes come from the type scale only.
font-weight error Only the system's font weights exist.
font-family error Only the system's font families exist.
spacing-scale error Padding, margin and gaps use the spacing steps only.
radius-scale error Corner radius uses the radius steps only.
shadow-scale error Shadows use the elevation steps only.
motion-duration error Durations come from the motion profile only.
motion-easing error Easings come from the motion profile only.
no-scale-zero error Never animate in from scale(0); start near the enter scale with a fade.
no-gradient-text warn No gradient-filled text.
ui-case warn Button and menu labels follow the system's case.
no-emoji warn No emoji in product UI.
no-token-override error App CSS may not redefine the system's variables or theme keys.
glass-on-content warn Glass is for chrome (nav, dialogs, popovers), never tables, lists or body text.
display-size warn The display font is for headlines at text-2xl and up.

If a rule must be broken, say so on the line before, with a reason. The check counts these:

// auto-design-allow no-arbitrary-value: matches the partner logo's fixed aspect ratio

In CI

Add one step to the app's workflow.

- run: npx auto-design check
