Quiet design system

Calm, dense and precise. Built for dashboards and tools people use all day.

Install

Add the system to any Tailwind v4 app, then lint it. Agents read DESIGN.md before writing UI.

npx auto-design add ./r/ --components all
npx shadcn@latest add /r/base.json
npx auto-design check

Every surface

The same tokens on each surface the product touches. Where a surface owns its own look, like a text thread or a chat app, the brand travels through images, accents and words.

Color

43 of 43 contrast checks pass in light and dark mode.

Type

Geist Variable, Geist Mono Variable. Product screens stop at 3xl; larger steps are for marketing.
