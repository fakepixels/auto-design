Components

Every component in the system, styled to its rules. Install one, some or all.

Avatar

People and workspaces.

Badge

Status and labels, always with text.

Button

Buttons with one primary variant per view.

Card

Grouped content on the page.

Code block

Syntax-highlighted code in the system's colors (Shiki, server-rendered).

Collection

Products, posts or reasons under the first screen: each item in a card on an even grid.

Dialog

Modal dialogs that enter from the system's enter scale.

Hero

A landing page's first screen: the headline, one line and the actions, with nothing decorative beside them.

Input

Text input sized to match buttons.

Label

Form labels.

Message

Chat messages and tool-call rows for agent UI.

Separator

A hairline between groups.

Site header

A landing page's header: the mark and name, then the links.

Skeleton

Loading placeholders.

Switch

On and off settings.

Table

Data tables with tabular numbers.

Tabs

Switch between views of the same thing.

Textarea

Multi-line text input.

Toaster

Toasts by Sonner, styled with system tokens.
