Words

The animation redraws as you type. Lists take one item per line.

Use it

Renders every frame in the system's own type and colors, in the words and format above. MP4, WebM and GIF need ffmpeg; HTML and PNG frames don't.

npx auto-design animate end-card --out end-card.mp4

One self-contained file that plays in any browser. Embed it in an iframe, or open it and record your screen.

Coding agents call the MCP server's render_animation tool with the same words, and get a file back.

render_animation { "id": "end-card", "format": "landscape", "out": "end-card.mp4" }
